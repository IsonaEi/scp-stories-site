隱私權政策

scp-stories 應用程式（高休謨讀檔人｜SCP 繁中故事）

scp-stories 是頻道擁有者自己使用的上傳程式，不對外提供服務。

存取哪些資料

經頻道擁有者本人透過 Google 授權後，程式只存取該頻道自己的資料：上傳影片、設定縮圖（youtube.upload 權限），以及讀取該頻道影片的處理狀態（youtube.readonly 權限）。另外以 API 金鑰讀取觀眾在本頻道影片下的公開留言（留言者的公開顯示名稱與留言內容）。

怎麼保存與使用

授權權杖與留言只存在頻道擁有者自己的電腦上。留言只供擁有者閱讀，保存不超過 30 天。不收集留言以外的任何個人資料，不出售、不分享給第三方，也不用於廣告。

撤銷授權

可隨時在 Google 帳戶的第三方存取設定 移除 scp-stories 的權限。

本程式使用 YouTube API 服務，適用 YouTube 服務條款 與 Google 隱私權政策。
